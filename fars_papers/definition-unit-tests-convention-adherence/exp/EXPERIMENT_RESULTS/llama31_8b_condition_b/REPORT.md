# Condition B (Neutral Checks) -- Llama-3.1-8B-Instruct

## Experiment Overview

Evaluated the engagement-matched neutral-checks baseline (Condition B) on Llama-3.1-8B-Instruct across ErdosConventionsBench (300 items, 3 families). The model receives the glossary, k=3 neutral verified facts (whose answers are identical under both glossary and alternate conventions), and then the main question. Uses the V3 "verified facts" approach where check Q&A pairs are provided as demonstrations rather than generated by the model.

## Setup

- **Model**: meta-llama/Llama-3.1-8B-Instruct
- **Condition**: B (glossary + 3 neutral verified facts + main question)
- **Benchmark**: ErdosConventionsBench (300 items: 100 asymptotics, 100 completeness, 100 convolution)
- **Decoding**: Greedy (temperature=0), max_tokens=2048
- **Prompt version**: V3 (verified facts, chat format)
- **Inference**: vLLM batched chat inference via TrainService (1x GPU)

## Key Results

| Metric | Value |
|--------|-------|
| **Overall accuracy** | **58.7%** (176/300) |
| Asymptotics | 92.0% (92/100) |
| Completeness | 21.0% (21/100) |
| Convolution | 63.0% (63/100) |
| Alternate convention match rate | 9.3% (28/300) |

Note: Uses robust answer extraction (boxed + heuristic fallbacks for truncated outputs). Check accuracy is N/A for Condition B under V3 (verified facts are provided in the prompt, not generated by the model).

## Comparison with Condition A (Glossary-Only) on Llama-3.1-8B

| Metric | A (Glossary-only) | B (Neutral checks) | Diff (B - A) |
|--------|-------------------|---------------------|--------------|
| Overall | 56.7% | 58.7% | +2.0pp |
| Asymptotics | 74.0% | 92.0% | +18.0pp |
| Completeness | 30.0% | 21.0% | -9.0pp |
| Convolution | 66.0% | 63.0% | -3.0pp |
| Alt rate | 11.0% | 9.3% | -1.7pp |

## Key Observations

1. **Near-identical overall to Condition A**: B (58.7%) is very close to A (56.7%), similar to the Qwen model pattern where neutral checks did not meaningfully improve over glossary-only.

2. **Mixed per-family effects**: Asymptotics improved substantially (+15pp) while completeness and convolution actually decreased. The neutral facts appear to help on some families but hurt on others, with the net effect being roughly zero.

3. **Still far below Qwen**: Overall 58.7% vs Qwen's 90.0% on Condition B confirms the large capability gap between the general-purpose and math-specialized models.

4. **Slightly lower alternate rate**: 9.3% vs 11.0% for Condition A, a minor reduction in convention confusion.

5. **Engagement-matched control established**: B provides the fair baseline for comparison with C (discriminative DUT), since both conditions present the same amount of supplementary information.
