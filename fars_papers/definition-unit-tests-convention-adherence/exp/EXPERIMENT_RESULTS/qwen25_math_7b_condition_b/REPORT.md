# Condition B (Neutral Checks) -- Qwen2.5-Math-7B-Instruct

## Experiment Overview

Evaluated the engagement-matched neutral-checks baseline (Condition B) on Qwen2.5-Math-7B-Instruct. The model receives the glossary, k=3 neutral verified facts (whose answers are identical under both glossary and alternate conventions), and then the main question. Uses the V3 "verified facts" approach where check Q&A pairs are provided as demonstrations rather than generated by the model.

## Setup

- **Model**: Qwen/Qwen2.5-Math-7B-Instruct
- **Condition**: B (glossary + 3 neutral verified facts + main question)
- **Benchmark**: ErdosConventionsBench (300 items: 100 asymptotics, 100 completeness, 100 convolution)
- **Decoding**: Greedy (temperature=0), max_tokens=2048
- **Prompt version**: V3 (verified facts, chat format)
- **Inference**: vLLM batched chat inference via TrainService (1x GPU)

## Key Results

| Metric | Value |
|--------|-------|
| **Overall accuracy** | **90.0%** (270/300) |
| Asymptotics | 97.0% (97/100) |
| Completeness | 79.0% (79/100) |
| Convolution | 94.0% (94/100) |
| Alternate convention match rate | 7.0% (21/300) |

## Key Observations

1. **Similar to Condition A**: B (90.0%) is nearly identical to A (90.3%), indicating that neutral verified facts do not meaningfully improve over the glossary-only baseline. This is expected since neutral facts, by definition, don't discriminate between conventions.

2. **Strong engagement-matched control**: B serves as a fair control for C because both conditions present the same amount of supplementary information (3 verified facts). Any C-B difference is attributable to the discriminative nature of the checks, not the additional context.

3. **Slightly higher alternate rate**: 7.0% vs A's 6.3%, suggesting neutral facts occasionally introduce ambiguity.
