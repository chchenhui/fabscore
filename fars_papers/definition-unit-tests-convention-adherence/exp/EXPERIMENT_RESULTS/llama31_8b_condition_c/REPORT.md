# Condition C (Discriminative DUT) -- Llama-3.1-8B-Instruct

## Experiment Overview

Evaluated the proposed Definition Unit Tests method (Condition C) on Llama-3.1-8B-Instruct across ErdosConventionsBench (300 items, 3 families). The model receives the glossary, k=3 discriminative verified facts (whose answers differ under glossary vs alternate conventions), and then the main question. Uses the V3 "verified facts" approach where check Q&A pairs are provided as demonstrations rather than generated by the model.

## Setup

- **Model**: meta-llama/Llama-3.1-8B-Instruct
- **Condition**: C (glossary + 3 discriminative verified facts + main question)
- **Benchmark**: ErdosConventionsBench (300 items: 100 asymptotics, 100 completeness, 100 convolution)
- **Decoding**: Greedy (temperature=0), max_tokens=2048
- **Prompt version**: V3 (verified facts, chat format)
- **Answer extraction**: Robust (boxed + heuristic fallbacks for truncated outputs)
- **Inference**: vLLM batched chat inference via TrainService (1x GPU)

## Key Results

| Metric | Value |
|--------|-------|
| **Overall accuracy** | **81.3%** (244/300) |
| Asymptotics | 96.0% (96/100) |
| Completeness | 82.0% (82/100) |
| Convolution | 66.0% (66/100) |
| Alternate convention match rate | 2.0% (6/300) |

## Full A/B/C Comparison on Llama-3.1-8B-Instruct

| Metric | A (Glossary-only) | B (Neutral checks) | C (Discriminative DUT) | Diff (C - B) |
|--------|-------------------|---------------------|------------------------|--------------|
| Overall | 56.7% | 58.7% | **81.3%** | **+22.7pp** |
| Asymptotics | 74.0% | 92.0% | 96.0% | +4.0pp |
| Completeness | 30.0% | 21.0% | 82.0% | +61.0pp |
| Convolution | 66.0% | 63.0% | 66.0% | +3.0pp |
| Alt rate | 11.0% | 9.3% | 2.0% | -7.3pp |

## Statistical Significance (Bootstrap CI)

- **C - B**: +22.7pp, Bootstrap 95% CI [+16.0%, +29.3%], **excludes zero** (statistically significant)
- **C - A**: +24.7pp, Bootstrap 95% CI [+18.0%, +31.3%], **excludes zero** (statistically significant)
- 10,000 resamples, 300 paired items

## Key Observations

1. **Large and significant improvement**: Condition C (81.3%) outperforms both A (56.7%) and B (58.7%) by a wide margin. The +22.7pp improvement over B is statistically significant with CI [+16.0%, +29.3%].

2. **Completeness gains are dramatic**: The completeness family shows the largest gain, from 21% (B) to 82% (C), a +61pp improvement. Discriminative checks effectively ground the "sufficiently large integers" convention.

3. **Asymptotics also improved**: From 92% (B) to 96% (C), a +4pp gain on an already strong family.

4. **Convolution shows modest gains**: 63% (B) to 66% (C), +3pp. The convolution family remains hardest for Llama, likely due to numeric computation difficulty rather than convention confusion.

5. **Near-zero alternate rate**: 2.0% of predictions match the alternate convention (down from 9.3% under B and 11.0% under A), confirming that discriminative checks strongly reduce convention confusion.

6. **Larger DUT effect than Qwen**: On Qwen2.5-Math-7B, C-B was +5.0pp (90%->95%). On Llama-3.1-8B, C-B is +22.7pp (58.7%->81.3%). The DUT method provides proportionally larger gains when the baseline model has lower convention adherence.
