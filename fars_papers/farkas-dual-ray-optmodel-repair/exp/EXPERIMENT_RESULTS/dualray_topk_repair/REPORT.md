# DualRay Repair Experiment Report (Updated with Optimization)

## Experiment Overview

Evaluated the DualRay feedback methods for repairing infeasible LP instances generated by Qwen2.5-7B-Instruct on the MAMO benchmark. Tested three conditions:
- **Condition B**: DualRay-TopK (names only, K=5, greedy) -- original method
- **Condition C+**: DualRay-TopK+Weights (normalized weights, K=10, best-of-6) -- optimized method
- **IIS-TopK best-of-6**: Control baseline with same enhanced prompt, K=10, best-of-6

## Setup

- **Model**: Qwen/Qwen2.5-7B-Instruct
- **Infeasible subset**: 31 instances from attempt-0 (9 EasyLP, 22 ComplexLP)
- **Condition B**: K=5, greedy decoding (temperature=0.0), constraint names only
- **Condition C+**: K=10, best-of-6 (1 greedy + 5 at temp=0.7, seed=42), normalized Farkas weights, enhanced repair prompt
- **IIS best-of-6**: K=10, best-of-6, enhanced repair prompt (control)
- **GPU**: 1x GPU via TrainService

|--------|---------------|----------------|---------------|-----------------|

## Key Observations

1. **DualRay+Weights (C+) outperforms IIS-TopK**: 3/31 vs 2/31 repairs, with EasyLP_620 being a unique DualRay success (3/6 samples passed vs 0/6 for IIS).
2. **Quantitative weights dramatically improve infeasibility resolution**: For 8+ instances, DualRay+Weights achieves >80% feasibility rate while IIS achieves 0%. The weights help the LLM understand which constraints to modify.
3. **Condition B (names only) is insufficient**: Without multiplier weights, DualRay ranking provides no advantage over IIS-TopK. The quantitative signal is the key differentiator.
4. **Best-of-N sampling is critical**: EasyLP_34 and EasyLP_620 required sampling diversity; greedy decoding alone missed them.
5. **ComplexLP remains extremely hard**: No ComplexLP instances were correctly repaired by any method, though DualRay+Weights makes many feasible (wrong objective).
6. **Enhanced prompt contributes**: Explicit repair strategies guide the LLM toward more productive edits, complementing the quantitative feedback.
