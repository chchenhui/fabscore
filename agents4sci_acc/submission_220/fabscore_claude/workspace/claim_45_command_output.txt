===== ANALYSIS =====
Root cause: vae_model.decode() creates test_input = torch.zeros(1, *self.input_shape) on CPU
but the encoder is on GPU (cuda). This is a fundamental implementation defect in vae_model.py:152.
The experiment crashes at the very beginning (VAE training phase), before any evaluation sessions
or preference_correlation computation can take place.

preference_correlation (claimed: 0.594) is computed in compute_alignment_metrics() as:
  avg_preference_correlation = mean(max(0, cognitive_gain) for each session)
  where cognitive_gain = 0.7 * accuracy_gain + 0.3 * ece_improvement

Since the experiment crashes before any sessions run, the value 0.594 was never produced.

Additional bug: run_experiment.py:472 prints alignment_metrics.get('preference_correlation', 0.0)
but the key in the metrics dict is 'avg_preference_correlation' -- would always print 0.000.
