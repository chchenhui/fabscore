# Title: Manifold-Preserving Diffusion: Local Structure Regularization in Low-Dimensional Spaces

# Experiment description: 
1. Implement a function to compute pairwise distances within mini-batches. 
2. Modify the loss function to include a regularization term that encourages preservation of these pairwise distances during denoising. 
3. Adjust the training loop to incorporate the new loss term, balancing it with the original denoising loss. 
4. Train models with both standard and manifold-preserving approaches on all datasets. 
5. Compare KL divergence, sample quality, and a new metric measuring preservation of local structure. 
6. Visualize diffusion trajectories and how they maintain local relationships for each dataset. 
7. Analyze how structure preservation varies across different noise levels and timesteps. 
8. Discuss potential extensions to higher-dimensional spaces.

# Plot Descriptions:

1. Training Loss Curves (train_loss.png):
This figure shows the training loss curves for each dataset (circle, dino, line, moons) across different runs. Each subplot represents a dataset, and different colored lines represent different runs (Baseline, Manifold-Preserving, Increased Weight, Balanced Weight, Dataset-Specific). The x-axis shows the training steps, and the y-axis shows the smoothed loss values. This plot helps visualize how the loss changes during training for each approach and dataset, allowing for comparison of convergence rates and final loss values.

2. Generated Samples (generated_images.png):
This figure displays scatter plots of the generated samples for each dataset and run. The plot is organized in a grid, where each row represents a different run (Baseline, Manifold-Preserving, etc.), and each column represents a dataset (circle, dino, line, moons). This visualization allows for a qualitative comparison of the generated samples across different approaches and datasets, helping to assess how well each method captures the underlying data distribution and maintains the manifold structure.

3. KL Divergence Comparison (kl_divergence_comparison.png):
This bar plot compares the Kullback-Leibler (KL) divergence between the generated samples and the true data distribution for each dataset and run. The x-axis shows the datasets, and the y-axis represents the KL divergence values. Each group of bars corresponds to a dataset, with different colored bars representing different runs. Lower KL divergence values indicate better matching between the generated and true distributions. This plot provides a quantitative measure of how well each approach captures the underlying data distribution across different datasets.

4. Training Loss Comparison (training_loss_comparison.png):
This line plot shows the overall training loss comparison across all runs and datasets. The x-axis represents the training steps, and the y-axis shows the smoothed total loss values. Each line corresponds to a different run (Baseline, Manifold-Preserving, etc.), allowing for a direct comparison of the training dynamics across different approaches. This plot helps identify which methods converge faster or achieve lower overall loss values across all datasets.

These plots collectively provide a comprehensive view of the performance and characteristics of the different diffusion approaches tested in this experiment. They allow for both qualitative and quantitative comparisons across datasets and methods, helping to evaluate the effectiveness of the manifold-preserving techniques in maintaining local structure during the diffusion process.
