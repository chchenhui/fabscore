\subsection{External Memory Module}
The external memory module in our MAT model is a differentiable memory structure that supports efficient read and write operations. The memory is implemented as a matrix \( M \in \mathbb{R}^{N \times d} \), where \( N \) is the memory size and \( d \) is the dimensionality of the memory vectors. At each time step \( t \), the model can read from and write to the memory, allowing it to store and retrieve information relevant to the input sequence.

% Memory read operation
\subsubsection{Memory Read Operation}
The memory read operation retrieves relevant information from the memory based on the current input. Given the input representation \( x_t \), the read operation computes a set of attention weights \( \alpha_t \) over the memory slots:
\[
\alpha_t = \text{softmax}(x_t W_r M^T)
\]
where \( W_r \) is a learnable weight matrix. The read vector \( r_t \) is then computed as a weighted sum of the memory slots:
\[
r_t = \sum_{i=1}^{N} \alpha_{t,i} M_i
\]

% Memory write operation
\subsubsection{Memory Write Operation}
The memory write operation updates the memory with new information from the input sequence. Given the input representation \( x_t \), the write operation computes a write vector \( w_t \) and a set of write weights \( \beta_t \):
\[
w_t = x_t W_w
\]
\[
\beta_t = \text{softmax}(x_t W_\beta)
\]
where \( W_w \) and \( W_\beta \) are learnable weight matrices. The memory is then updated as follows:
\[
M_i \leftarrow (1 - \beta_{t,i}) M_i + \beta_{t,i} w_t
\]

\subsection{Integration into GPT Model}
The external memory module is integrated into the GPT model by incorporating the memory read and write operations within the forward pass of the model. At each time step \( t \), the input representation \( x_t \) is augmented with the read vector \( r_t \) from the memory:
\[
x_t' = x_t + r_t
\]
The augmented input \( x_t' \) is then passed through the transformer layers. The memory write operation is performed at the end of each time step to update the memory with new information from the input sequence.

The training procedure for our MAT model follows the standard approach for training transformer-based language models, with additional steps to handle the memory state. Our Memory-Augmented Transformer (MAT) model builds upon the standard GPT architecture by incorporating an external memory module. The core components of the MAT model include the transformer layers, the external memory module, and the memory read/write operations. The transformer layers follow the standard design, consisting of multi-head self-attention and feed-forward neural network layers \citep{vaswani2017attention}. The external memory module is designed to store and retrieve information beyond the fixed context window, enabling the model to maintain context over extended sequences.

% Design of the external memory module
\subsection{External Memory Module}
The external memory module in our MAT model is a differentiable memory structure that supports efficient read and write operations. The memory is implemented as a matrix \( M \in \mathbb{R}^{N \times d} \), where \( N \) is the memory size and \( d \) is the dimensionality of the memory vectors. At each time step \( t \), the model can read from and write to the memory, allowing it to store and retrieve information relevant to the input sequence.

% Memory read operation
\subsubsection{Memory Read Operation}
The memory read operation retrieves relevant information from the memory based on the current input. Given the input representation \( x_t \), the read operation computes a set of attention weights \( \alpha_t \) over the memory slots:
\[
\alpha_t = \text{softmax}(x_t W_r M^T)
\]
