Optimizers play a crucial role in training neural networks by adjusting the model parameters to minimize the loss function. Different optimizers have unique characteristics that influence the learning process. For instance, SGD \cite{goodfellow2016deep} is known for its simplicity and effectiveness in many scenarios, while Adagrad introduces adaptive learning rates to handle varying gradient magnitudes. AdamW \cite{loshchilov2017adamw} combines the benefits of adaptive learning rates with weight decay regularization, making it a popular choice for many applications.

The model parameters \( \theta \) are trained to minimize the loss function \( \mathcal{L}(\theta) \) using different optimizers.

\subsection{Training Procedure}
The training procedure involves:
\begin{itemize}
    \item Initializing the model parameters \( \theta \) and the optimizer.
    \item Dividing the dataset \( \mathcal{D} \) into training set \( \mathcal{D}_{\text{train}} \) and validation set \( \mathcal{D}_{\text{val}} \).
    \item Training the model on \( \mathcal{D}_{\text{train}} \) for a fixed number of updates, logging performance at regular intervals.
    \item Evaluating the model on \( \mathcal{D}_{\text{val}} \) to measure final validation accuracy and training stability.
\end{itemize}
We use a batch size of 512 and a total of 7500 updates per experiment. The learning rate is set to 1e-3, with a warmup period of 50 steps. Metrics include speed to grokking (point at which validation accuracy exceeds 99\%), final validation accuracy, and training stability.

\begin{itemize}

    \item \textbf{RMSprop}: Root Mean Square Propagation with a learning rate of 1e-3.
    \item \textbf{Adagrad}: Adaptive Gradient Algorithm with a learning rate of 1e-3.
    \item \textbf{AdamW}: Adam with decoupled weight decay \cite{loshchilov2017adamw} with a learning rate of 1e-3, betas of (0.9, 0.98), and weight decay of 0.5.
\end{itemize}
Each optimizer is configured with its default parameters, except for the learning rate, which is set to 1e-3 for consistency.

\subsection{Evaluation Metrics}
We use the following metrics to evaluate each optimizer:
\begin{itemize}

    \item \textbf{Final Validation Accuracy}: Validation accuracy at the end of training.
    \item \textbf{Training Stability}: Consistency of the training process, measured by variance in training loss and accuracy.

These metrics provide a comprehensive view of each optimizer's performance, highlighting their strengths and weaknesses in different aspects of the training process.
