# Title: Linear Diffusion Steering: Controlled Generation via Trajectory Guidance in Low-Dimensional Diffusion Models
# Experiment description: 1. Implement a linear path definition function in 2D space. 2. Modify NoiseScheduler to include a linear guidance term with adjustable strength. 3. Adapt the sampling process to use the guided scheduler. 4. Train models on all datasets using the original method. 5. Generate samples using both standard and guided approaches with varying guidance strengths. 6. Visualize diffusion trajectories and final samples. 7. Measure path adherence using mean squared distance from the defined path. 8. Compare sample quality (KL divergence) and path adherence across guidance strengths. 9. Analyze the trade-off between following the defined path and maintaining data distribution characteristics.

# Plot Descriptions

1. Generated Samples (generated_samples.png):
   This figure provides a comprehensive visual comparison of the generated samples across all runs and datasets. It consists of a 5x4 grid of scatter plots, where each row represents a different run (Baseline, Linear (0.5), Linear (0.1), Linear (1.0), and Circular (1.0)), and each column represents a different dataset (circle, dino, line, and moons).

   Key features:
   - Each scatter plot shows the distribution of 10,000 generated samples in 2D space.
   - The color of the points in each plot corresponds to the specific run.
   - For linear guidance runs, a red dashed line from (-1, -1) to (1, 1) indicates the target path.
   - For the circular guidance run, a red dashed circle represents the target path.
   - The plot titles indicate the dataset and the type of guidance used.
   - The x and y axes are consistently scaled from -2 to 2 across all plots for easy comparison.

   This plot allows for a direct visual comparison of how different guidance methods and strengths affect the generated samples for each dataset. It clearly shows the trade-off between following the guided path and maintaining the original data distribution.

2. KL Divergence Comparison (kl_divergence_comparison.png):
   This bar plot compares the Kullback-Leibler (KL) divergence between the generated samples and the original data distribution across all runs and datasets.

   Key features:
   - The x-axis represents the four datasets (circle, dino, line, and moons).
   - The y-axis shows the KL divergence values.
   - Each run is represented by a group of bars with different colors.
   - A legend identifies which color corresponds to which run.

   This plot quantifies how much the generated distributions deviate from the original data distributions. Higher KL divergence values indicate greater deviation. It allows for easy comparison of the impact of different guidance methods and strengths on maintaining the original data distribution characteristics.

3. Path Adherence Comparison (path_adherence_comparison.png):
   This bar plot compares the path adherence (measured as Mean Squared Error from the defined path) across all runs and datasets.

   Key features:
   - The x-axis represents the four datasets (circle, dino, line, and moons).
   - The y-axis shows the path adherence values (lower values indicate better adherence).
   - Each run is represented by a group of bars with different colors.
   - A legend identifies which color corresponds to which run.

   This plot quantifies how closely the generated samples follow the defined guidance path. Lower values indicate better adherence to the path. It allows for easy comparison of the effectiveness of different guidance methods and strengths in controlling the generation process.

4. KL Divergence vs Path Adherence Trade-off (kl_path_tradeoff.png):
   This scatter plot visualizes the trade-off between KL divergence and path adherence for each run and dataset.

   Key features:
   - The x-axis represents the KL divergence.
   - The y-axis represents the path adherence (MSE).
   - Each point on the plot represents a specific run-dataset combination.
   - Different colors and markers are used to distinguish between runs.
   - A legend identifies which color/marker combination corresponds to which run.

   This plot provides a clear visualization of the trade-off between maintaining the original data distribution (lower KL divergence) and following the guided path (lower path adherence). Points closer to the origin represent better overall performance. The plot allows for easy identification of which guidance methods and strengths achieve the best balance for each dataset.

These plots, when analyzed together, provide a comprehensive understanding of the performance and characteristics of different guidance methods and strengths across various datasets. They clearly illustrate the trade-offs involved in guided diffusion and can inform decisions about which approach might be most suitable for specific applications or data types.
