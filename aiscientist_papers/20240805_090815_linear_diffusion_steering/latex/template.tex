\section{Background}
\label{sec:background}

Diffusion models have emerged as a powerful class of generative models, achieving state-of-the-art results in various domains \cite{yang2023diffusion}. The core idea behind diffusion models, introduced by \citet{sohl-dickstein15}, is to define a forward diffusion process that gradually adds Gaussian noise to the data, and then learn a reverse diffusion process that removes this noise step by step. This reverse process is typically parameterized by a neural network and trained to predict the noise at each step, allowing for high-quality sample generation.

The Denoising Diffusion Probabilistic Models (DDPM) framework, proposed by \citet{ddpm}, has become a cornerstone in the field. DDPMs define a fixed Markov chain for the forward process and use a neural network to learn the reverse process. This approach has shown remarkable success in generating high-quality samples while maintaining stable training dynamics.

Recent work has explored guided diffusion, where the generation process is steered towards desired outcomes. However, most existing approaches focus on high-dimensional data like images, leaving the potential of guided diffusion for low-dimensional data largely unexplored.

\subsection{Problem Setting}

In this work, we focus on controlled generation in low-dimensional diffusion models. We consider a dataset $\mathcal{D} = \{x_i\}_{i=1}^N$ where $x_i \in \mathbb{R}^d$ and $d$ is small (in our case, $d=2${)}. Our goal is to train a diffusion model that can generate samples from the data distribution while following a predefined path in the low-dimensional space.

We define a guidance path $P: [0, 1] \rightarrow \mathbb{R}^d$ that specifies the desired trajectory for the generated samples. In our experiments, we consider both linear and circular paths:

\begin{itemize}
    \item Linear path: $P_{\text{linear}}(t) = (1-t)(-1, -1) + t(1, 1)$
    \item Circular path: $P_{\text{circular}}(t) = (\cos(2\pi t), \sin(2\pi t))$
\end{itemize}

We introduce a guidance strength parameter $\lambda \in [0, 1]$ that controls the trade-off between following the predefined path and maintaining the characteristics of the original data distribution. Our objective is to develop a method that can effectively balance these two goals, allowing for controlled generation while preserving the quality and diversity of the generated samples.

This problem setting presents unique challenges and opportunities in the context of low-dimensional diffusion models, as the reduced dimensionality allows for more direct control and visualization of the generation process. Unlike previous work on guided diffusion, which often focuses on complex, high-dimensional data, our approach aims to provide precise control in low-dimensional spaces where interpretability and fine-grained control are crucial.

\section{Method}
\label{sec:method}

Building upon the DDPM framework introduced in Section \ref{sec:background}, we propose a novel approach for guided diffusion in low-dimensional spaces. Our method introduces a guidance mechanism that steers the generation process towards predefined paths while maintaining the benefits of diffusion models.

\subsection{Guided Diffusion Process}

We modify the standard diffusion process to incorporate guidance. Given a predefined path $P: [0, 1] \rightarrow \mathbb{R}^d$ and a guidance strength parameter $\lambda \in [0, 1]$, we define the guided denoising step as:

\begin{equation}
    x_{t-1} = \mu_\theta(x_t, t) + \lambda(P(1-t/T) - x_t) + \sigma_t z
\end{equation}

where $\mu_\theta$ is the learned denoising model, $T$ is the total number of diffusion steps, $\sigma_t$ is the noise scale at step $t$, and $z \sim \mathcal{N}(0, I)$.

The guidance term $\lambda(P(1-t/T) - x_t)$ pulls the sample towards the target point on the path. The strength parameter $\lambda$ controls the trade-off between following the path and maintaining the learned distribution.

\subsection{Path Definitions}

We consider two types of guidance paths:

\begin{itemize}
    \item Linear path: $P_{\text{linear}}(t) = (1-t)(-1, -1) + t(1, 1)$
    \item Circular path: $P_{\text{circular}}(t) = (\cos(2\pi t), \sin(2\pi t))$
\end{itemize}

These paths allow us to evaluate our method's effectiveness in guiding the generation process along both linear and non-linear trajectories.

\subsection{Model Architecture}

We use a simple MLP architecture for the denoising model $\mu_\theta$:

\begin{itemize}
    \item Sinusoidal embeddings for time and input (dimension 128)
    \item 3 hidden layers with 256 units each and ReLU activations
    \item Residual connections between hidden layers
    \item Final linear layer to output the denoised sample
\end{itemize}

This architecture is designed to capture high-frequency patterns effectively in low-dimensional data.

\subsection{Training and Sampling}

We train the model using the standard DDPM objective:

\begin{equation}
    \mathcal{L} = \mathbb{E}_{t,x_0,\epsilon}[\|\epsilon - \epsilon_\theta(x_t, t)\|^2]
\end{equation}

where $\epsilon$ is the noise added to the data, and $\epsilon_\theta$ is the noise prediction network.

During sampling, we use the guided diffusion process described earlier. This allows us to generate samples that follow the predefined path while maintaining some characteristics of the learned distribution.

By adjusting the guidance strength $\lambda$, we can control the balance between path adherence and distribution matching. This provides a flexible framework for controlled generation in low-dimensional spaces, addressing the challenges outlined in Section \ref{sec:intro}.

We implement our guided diffusion approach by modifying the denoising process to incorporate the predefined path. The guided denoising step is defined as:

    \item Extending the approach to higher-dimensional data, potentially by adapting techniques from diffusion models for tabular data.
    \item Investigating more sophisticated guidance mechanisms that better preserve the original data distribution while maintaining strong path adherence.
    \item Developing adaptive guidance strength methods that automatically adjust based on local properties of the data distribution and guidance path.
    \item Exploring applications in specific domains, such as robotics or scientific computing.
\end{itemize}

In conclusion, our work on guided diffusion for low-dimensional data opens up new possibilities for controlled generation in diffusion models. While challenges remain in balancing control and distribution matching, this approach provides a valuable foundation for future research in guided generative modeling and controlled sample generation in low-dimensional spaces.
