### Plan for Experiments

We will conduct a series of experiments to test the effectiveness of layer-wise learning rate adaptation. The idea is to assign different learning rates to different layers, with deeper layers having lower learning rates. We will compare the training dynamics, convergence speed, and final performance with the baseline model.

#### Experiment 1: Linear Decay of Learning Rate
- Learning rate for each layer will linearly decay from the initial learning rate to a lower bound.

#### Experiment 2: Exponential Decay of Learning Rate
- Learning rate for each layer will exponentially decay from the initial learning rate to a lower bound.

#### Experiment 3: Step Decay of Learning Rate
- Learning rate for each layer will decay in steps, with a fixed reduction factor every few layers.

#### Experiment 4: Cosine Decay of Learning Rate
- Learning rate for each layer will follow a cosine decay schedule.

#### Experiment 5: Inverse Square Root Decay of Learning Rate
- Learning rate for each layer will follow an inverse square root decay schedule.

### Implementation Steps

1. Modify the `configure_optimizers` function in `experiment.py` to support layer-wise learning rates.
2. Implement the different decay strategies for learning rates.
3. Run each experiment using the command `python experiment.py --out_dir=run_i` where `i` is the run number.
